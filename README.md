A make.fun entry: sum up an ex in exactly one word.

## The word

**Freemium** — the ex was the free tier. Basic access cost nothing; everything that mattered was locked behind a subscription.

## Run it

```sh
node main.ts
```

Writes the word to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt` when set).
